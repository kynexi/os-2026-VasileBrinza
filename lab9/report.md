## Part 1 — See the calls of a real command

Executed:

```bash
strace -f -e trace=openat,read,write,close ls -l
```

The trace showed system calls used by `ls` to load libraries, read configuration files, access the current directory, and print the directory listing.

**Observe:**

1. `ls` uses the `write()` system call to print to the screen.
2. It writes to file descriptor `1`, which represents standard output (`stdout`).

Example from the trace:

```text
write(1, "total 44\n", 9) = 9
```

The captured trace contained approximately 60 system calls among the selected types.

## Part 2 — A program that calls the kernel directly

Created and compiled `syscalls.c`:

```bash
gcc -Wall -Wextra -o syscalls syscalls.c
./syscalls
```

**Actual output:**

```text
open returned descriptor 3
write sent 14 bytes
read got 14 bytes: hello, kernel
```

Then traced the program:

```bash
strace -e trace=openat,write,read,close ./syscalls
```

**Relevant system calls from the actual trace:**

```text
openat(AT_FDCWD, "note.txt", O_WRONLY|O_CREAT|O_TRUNC, 0644) = 3
write(1, "open returned descriptor 3\n", 27) = 27
write(3, "hello, kernel\n", 14) = 14
write(1, "write sent 14 bytes\n", 20) = 20
close(3) = 0
openat(AT_FDCWD, "note.txt", O_RDONLY) = 3
read(3, "hello, kernel\n", 63) = 14
write(1, "read got 14 bytes: hello, kernel"..., 33) = 33
close(3) = 0
```

**Observe:**

The first `openat()` returns descriptor `3` because descriptors `0`, `1`, and `2` are already reserved for standard input (`stdin`), standard output (`stdout`), and standard error (`stderr`), respectively.

After descriptor `3` is closed, the next `openat()` reuses it because it is the lowest available descriptor.

## Part 3 — Count one kind of call

Executed:

```bash
strace -c -e trace=write ./syscalls
```

**Actual result:**

| System call | Calls | Errors |
|---|---:|---:|
| `write` | 4 | 0 |

The four calls consist of one explicit `write()` to `note.txt` and three `write()` calls generated by `printf()` to display information in the terminal.

Two separate runs both reported four calls and zero errors.

## Conclusion

This lab demonstrated how `strace` exposes the system calls made by Linux programs. It showed that terminal output uses `write()` on descriptor `1`, that newly opened files receive the lowest available file descriptor, and that library functions such as `printf()` also result in system calls to the kernel.
